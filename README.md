## Reglas de Juego / Instrucciones

Kike en es un perrito que perdió a sus cachorritos y debera recuperarlos.

En el escenario hay 3 tipos de enemigos, uno más fuerte que el otro.
Cada uno quita cierta cantidad de puntos de vida a nuestro personaje.

Nuestro personaje deberá esquivar paredes y enemigos, romper paredes del tipo destructible para así poder pasar y llegar sanos y salvos al nuestr objetivo: los cachorritos de Kike

Las teclas que usaremos son solamente las flechas para el movimiento y la tecla enter para afirmar si reiniciar el juego
